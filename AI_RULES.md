# AI Rules for MyTerminal Development

Rules for AI coding assistants working on this project.

## Primary reference

- Before any work, read [CODE_WIKI.md](CODE_WIKI.md) for the project architecture, module ownership, key classes/functions, data flows, dependencies, and invariants. It is the single entry point for understanding the codebase and must be consulted first by every contributor and AI collaborator.

## User-facing copy

- Internal implementation constraints, audit guarantees, and instructions written to satisfy development requirements must not be shown as user-facing UI copy. UI text must serve an actual user task, decision, status, or recovery action.
